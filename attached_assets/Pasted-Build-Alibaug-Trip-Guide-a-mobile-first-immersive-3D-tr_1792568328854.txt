Build "Alibaug Trip Guide": a mobile-first, immersive 3D trip-guide
website for a 4-day trip (27-30 Nov 2026, 2 travellers, staying at Blue
Waves Resort, Varsoli, Alibaug). It is a handy illustrated GUIDE first,
with a Journey experience. I'll paste the itinerary at the end; follow
it exactly (times, hard rules, fallbacks).

STACK
- Vite + React + TypeScript, plain CSS with CSS variables, Zustand for
  state. HashRouter so GitHub Pages never 404s.
- 3D: three + @react-three/fiber + @react-three/drei. Motion: GSAP +
  ScrollTrigger (or framer-motion). Lazy-load the 3D chunk.
- vite-plugin-pwa: installable, itinerary data and graphics work
  offline. base path from an env var; README explains how to set it.
- GitHub Actions workflow to build and deploy to Pages. README covers
  dev, build, deploy and editing data.
- All content in /src/data as typed files (itinerary, places, food,
  checklists). No hard-coded content in components.

3D JOURNEY (the immersive part)
- A stylised soft-clay 3D coast diorama: sand islands extruded from
  shape paths, a water plane with a gentle animated shader (soft waves,
  foam near the shore), simple palms, a lighthouse, and fort shapes
  built from primitives. Lighting shifts toward golden hour for sunset
  stops.
- The day's route is a glowing dashed 3D tube. Places are floating 3D
  pins with an emoji badge. The couple (my PNGs as billboarded sprites
  with a soft shadow blob) travel along the route, bobbing, and switch
  pose by state (driving while moving, parked at stops, etc.).
- Scroll-driven camera fly-through along a CatmullRomCurve3 that follows
  the stops in order. On desktop add drag-to-orbit (limited angles) and
  mouse parallax. On mobile use a drag with momentum and tap to select.
  Tapping a pin focuses the camera and opens a bottom sheet (desktop: a
  side drawer) with that stop's details.
- Map positions: use stylised x/z positions in the data until I provide
  lat/lng. Never invent coordinates; flag missing ones in the README.
- Performance: dpr clamped (max 1.5 on mobile), instanced meshes, no
  heavy post-processing on mobile, pause rendering when the tab is
  hidden, aim for 60 fps on a mid-range phone. Provide a static poster
  fallback if WebGL is unavailable, prefers-reduced-motion is set or
  data-saver is on.
- A "Guide mode / Journey mode" switch so I can always use the plain
  list view.

WAVES WASHING FROM THE TOP
