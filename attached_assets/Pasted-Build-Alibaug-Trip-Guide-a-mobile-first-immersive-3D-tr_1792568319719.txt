Build "Alibaug Trip Guide": a mobile-first, immersive 3D trip-guide website for a 4-day trip (27-30 Nov 2026, 2 travellers, staying at Blue Waves Resort, Varsoli, Alibaug). It is a handy illustrated GUIDE first, with a Journey experience. I'll paste the itinerary at the end; follow it exactly (times, hard rules, fallbacks).

STACK

Vite + React + TypeScript, plain CSS with CSS variables, Zustand for state. HashRouter so GitHub Pages never 404s.
3D: three + @react-three/fiber + @react-three/drei. Motion: GSAP + ScrollTrigger (or framer-motion). Lazy-load the 3D chunk.
vite-plugin-pwa: installable, itinerary data and graphics work offline. base path from an env var; README explains how to set it.
GitHub Actions workflow to build and deploy to Pages. README covers dev, build, deploy and editing data.
All content in /src/data as typed files (itinerary, places, food, checklists). No hard-coded content in components.

3D JOURNEY (the immersive part)

A stylised soft-clay 3D coast diorama: sand islands extruded from shape paths, a water plane with a gentle animated shader (soft waves, foam near the shore), simple palms, a lighthouse, and fort shapes built from primitives. Lighting shifts toward golden hour for sunset stops.
The day's route is a glowing dashed 3D tube. Places are floating 3D pins with an emoji badge. The couple (my PNGs as billboarded sprites with a soft shadow blob) travel along the route, bobbing, and switch pose by state (driving while moving, parked at stops, etc.).
Scroll-driven camera fly-through along a CatmullRomCurve3 that follows the stops in order. On desktop add drag-to-orbit (limited angles) and mouse parallax. On mobile use a drag with momentum and tap to select. Tapping a pin focuses the camera and opens a bottom sheet (desktop: a side drawer) with that stop's details.
Map positions: use stylised x/z positions in the data until I provide lat/lng. Never invent coordinates; flag missing ones in the README.
Performance: dpr clamped (max 1.5 on mobile), instanced meshes, no heavy post-processing on mobile, pause rendering when the tab is hidden, aim for 60 fps on a mid-range phone. Provide a static poster fallback if WebGL is unavailable, prefers-reduced-motion is set or data-saver is on.
A "Guide mode / Journey mode" switch so I can always use the plain list view.
WAVES WASHING FROM THE TOP

A TideWash component: 3-4 layered SVG waves (aqua, deeper aqua, white foam, wet-sand tint) with a foam line and a few bubbles. On first load and when changing day, the water washes down from the top of the screen across the viewport, then recedes upward, revealing the page. About 1.8 s, eased. For reduced motion, use a simple fade.
Also a persistent, slow, ambient wave edge under the sticky header, and a small ripple whenever a stamp is collected.

Tapping the sand leaves a fading footprint or shell. The kiss.png couple sits parked on the sand on tablet and desktop. SCREENS AND FEATURES

Home: hero with lessgoo.png, title, dates, resort, a live countdown to 27 Nov 2026, "Start from Day 1" (glossy orange CTA) and "What's now?" (opens the stop matching the current time on trip days; otherwise Day 1 with a friendly message). Then "Jump to a day" (4 coloured cards with N/M done) and "Jump to a place" (category chips and place chips).
Days: day tabs, a coloured banner with progress, a button "Open the whole day's route in Google Maps", then collapsible stop cards: time, title, place art, tick when done. Expanded: the note, tabs for Tips / Food / Photos, and these buttons:
"From my location" (Google Maps directions, no origin)
"From " (origin = the previous different place; hide on the first stop)
"I'm here: stamp it!" (marks the stop done, collects the stamp, with a toast, confetti and the happy.png pose)
"Maps" (place search), "Photos" (Google Images search), "About"
Place page: art, stamp status, a fun fact, three tips, buttons (Stamp, Open in Maps, Navigate, Photos), an embedded Google map via iframe (https://www.google.com/maps?q=&output=embed; the provider is switchable in one config file), and "When you're here" linking to each visit. The resort page has an "Exact resort pin" input (address or lat,lng), saved and used for navigation to the resort.
Map: a real Leaflet map (OpenStreetMap, with attribution, a "locate me" button) as the 2D alternative to the 3D view, with the day selector, markers and the route polyline.
Stamps: a passport grid with my stamp art (SVG seal fallback); uncollected ones are greyscale and faded; N/total and a celebration at 100 per cent.
Prep: tickable checklists (Now, One week before, 48 hours before, Pack) and a note that all fares and times are estimates. Progress (done stops, stamps, ticks, pin, theme) is saved in localStorage inside try/catch and works if storage is empty.
